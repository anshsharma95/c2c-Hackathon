# 🌌 COSMOS — Explore the Universe

COSMOS is a space exploration website designed to bring the
wonders of the universe to life through interactive web experiences.

## ✨ Features

- Astronomy Picture of the Day (APOD) integration
- Date-based astronomical discoveries
- Dark, space-inspired user interface
- Smooth scrolling and animations
- Interactive Solar System — planned
- 3D space animations — in development

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- NASA astronomical data

## 🚀 Getting Started

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run `index.html` using a local development server,
   such as the Live Server extension.
4. Explore the website!
